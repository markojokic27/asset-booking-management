= Domain Model

== User
[options = "header", cols="1,1,2"]
|===
| Field | Type | Validation
| id - PK | BIGINT |  NOT NULL
| username | VARCHAR(50) | NOT NULL, UNIQUE, MIN=3, MAX=50
| surname | VARCHAR(100) | NOT NULL
| name | VARCHAR(100) | NOT NULL
| email | VARCHAR(100) | NOT NULL, UNIQUE, EMAIL FORMAT
| password | VARCHAR(100) | NOT NULL, MIN=8
| role | ENUM (EMPLOYEE, ADMIN, MANAGER)| NOT NULL
| status | ENUM (ACTIVE, INACTIVE)| NOT NULL, DEFAULT=ACTIVE
| departmentId - FK | BIGINT | NOT NULL
| manager_email | VARCHAR(100) | EMAIL FORMAT, NOT NULL
| benefit | ENUM (ALL, REC_PARK,?) | OPTIONAL
| note | VARCHAR(255) | OPTIONAL
| created_at | TIMESTAMP | NOT NULL, DEFAULT=NOW()
| last_modified_at | TIMESTAMP | NOT NULL, AUTO UPDATE
|===
