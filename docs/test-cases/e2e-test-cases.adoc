= Booking

== 10. Successful booking [POSITIVE]
User selects an available asset, chooses a time period and successfully creates a booking

[cols="1,1,1,1", options="header"]
|===
|Preconditions|Actor|Steps|Expected Result

|User is logged into the system. 
|Employee
a|
. Navigate to the Assets page
. Select a category
. Select an available asset
. Choose a valid date and time period
. Click "Book" / "Confirm Booking"
|Booking is created with status "Confirmed", Confirmation screen is displayed with booking ID, asset name, location and time, Confirmation email is sent to the user

|===

== 11. Attempt to book an already booked asset [NEGATIVE]
User attempts to book an asset that is already reserved for the same time period

[cols="1,1,1,1", options="header"]
|===
|Preconditions|Actor|Steps|Expected Result

|User is logged into the system. 
|Employee
a|
. Navigate to the Assets page
. Select a category (e.g. Laptops)
. Select an asset that is already booked
. Choose the same date and time period as the existing booking
. Click "Book" / "Confirm Booking"
|Error message is displayed: "This asset is already booked for the selected time period"

|===

== 12. Booking without a selected date [NEGATIVE]

|===

== 13. Booking an inactive asset [NEGATIVE]

[cols="1,1,1,1", options="header"]
|===
|Preconditions|Actor|Steps|Expected Result

[cols="1,1,1,1", options="header"]

|Manager
a|

. Review request details

|Booking status is updated to "Rejected", user is notified of the rejection, asset remains available for the requested time period
