= Asset Category Management

== 1. Successful creation of a new asset category

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin
a|
. Open "Add Category" form
. Fill required fields
. Click Save
|Category is created; confirmation message shown|
|===

== 2. Attempt to create a category with missing required fields

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin
a|
. Open "Add Category" form
. Leave some required fields empty
. Click Save
|System highlights missing fields; category not saved|
|===

== 3. Attempt to create a category with an existing name

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin; "Parking" exists
a|
. Open "Add Category" form
. Enter name "Parking"
. Fill other fields
. Click Save
|Warning about duplicate name; option to edit or cancel|
|===

== 4. Successful update of an existing asset category

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin; "Laptop" exists
a|
. Open "Edit" for "Laptop"
. Change fields as needed
. Click Save
|Changes saved; confirmation message displayed|
|===

== 5. Successful deletion of an asset category

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin; "Laptop" exists; no active bookings
a|
. Open "Edit" for "Laptop"
. Click Delete
. Confirm deletion
|Category marked inactive; confirmation message shown|
|===

== 6. Attempt to delete a category with active bookings

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin; "Laptop" has active/future bookings
a|
. Open "Edit" for "Laptop"
. Click Delete
. Confirm deletion
|Warning: cannot delete with active/future bookings|
|===

== 7. Attempt to save invalid data

[cols="1,1,1", options="header"]
|===
|Preconditions|Steps|Expected Result
|User logged in as Admin; "Laptop" exists
a|
. Open "Edit" for "Laptop"
. Enter invalid data (e.g., minimum booking duration set to 0 hours)
. Click Save
|Validation error shown; minimum booking duration must be at least 1 hour; changes not saved|
|===
